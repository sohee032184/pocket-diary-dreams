# Pocket Diary

제목: 중학생 소녀를 위한 감성적이고 다정한 용돈기입장 'My Pocket Diary'

1. 디자인 컨셉:

전체적으로 **파스텔톤(연한 핑크, 라벤더, 민트)**의 깔끔하고 귀여운 스타일로 디자인해줘.

둥글둥글한 버튼과 부드러운 애니메이션을 사용해서 딱딱한 가계부가 아닌 '다이어리' 느낌이 나게 해줘.

중학생 취향에 맞게 폰트는 가독성 좋으면서도 귀여운 스타일을 적용해줘.

2. 주요 기능:

대시보드: 이번 달 남은 잔액을 화면 상단에 크게 보여줘. (예: "이번 달 내 지갑은 ₩25,000 남았어! 🍯")

입력창: '수입/지출' 구분, '금액', '카테고리(식비, 문구, 덕질, 교통비, 기타)', '간단 메모'를 입력할 수 있게 해줘.

지출 내역 리스트: 아래쪽에 최신순으로 내역이 카드 형태로 나열되게 해줘. 지출 카테고리에 맞는 작은 아이콘(🍔, ✏️, 🎤 등)이 표시되면 좋겠어.

응원 메시지: 지출을 기록할 때마다 "오늘도 알뜰하게 잘 썼어!", "이건 정말 필요한 거였지? 칭찬해!" 같은 다정한 랜덤 응원 문구가 팝업이나 하단에 뜨게 해줘.

3. 특별한 기능:

소원 리스트(Wish List): 사고 싶은 물건과 가격을 적어두고, 용돈을 아껴서 얼마나 모았는지 퍼센트(%)로 보여주는 진행바(Progress Bar)를 만들어줘.

통계: 이번 달에 어떤 카테고리(예: 덕질, 편의점)에 돈을 가장 많이 썼는지 간단한 원형 차트로 보여줘.
